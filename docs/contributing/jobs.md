# VATSIM Radar Designer Application

Hello! For the first time since VATSIM Radar was created, we are hiring.

Today, we are searching for 2 roles:

- UI/UX Designer
- Graphical Designer (Aircraft Icons)

We are hiring because two persons responsible for those areas lack free time to work on those on regular basis.

## UI/UX Designer

### Requirements

1. You shall be familiar with Figma on a Junior+ or greater level
2. You shall be familiar with basic UI concepts, such as Material Design
3. You shall dislike default generic AI Tailwind design because it sucks and is present everywhere

### Responsibilities

1. Evaluate current design decisions and provide feedback on them, especially when it's not in Figma already (which
   means it was not created by a designer)
2. Redesign current pages that lack proper UI/UX (ex. Bookings, Events, Dashboard)
3. Create new pages, such as standalone User Page that is scheduled for v2.1 release

### Working process

1. You shall utilize existing Figma components. You are allowed to change them and to create new ones
2. You shall do review process of your design with lead designer (first and currently only designer of VATSIM Radar) -
   preferably in Telegram
3. You shall work on this on regular basis, at least few sessions per month. Obviously, this is a volunteer job, but I
   would really love if you would be interested in this and would not abandon us after you agree to join the team

We are currently looking for just one designer for this role. 

## Graphic Designer

### Requirements

1. You shall be familiar with Figma and Graphic Design on a basic level
2. You shall be familiar with basic Googling so you can find aircraft icons references
3. You will be required to insert your icons in code using any code editor, such as VS Code (with a help from me of course)

Look at current icons to understand what the job is: https://github.com/VATSIM-Radar/vatsim-radar/tree/next/app/assets/icons/aircraft

### Responsibilities / Working process

1. Review Github Issues for existing icons
2. Draw those icons in Figma (or Illustrator) following instruction and requirements that will be sent to you
3. Add them to code using instruction that will be given to you
4. Open a Pull Request to merge those icons to VATSIM Radar

We'll do an interview session to get to know each other.
